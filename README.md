# paper-digest-data

Daily data for **HydroAgent Paper Digest / 水利大模型文献日报** — new papers on large language models in
hydrology and water resources, listed at <https://hydroagentlab.com/paper-digest/>.

`papers.json` is written **only** by the HydroAgent collector server (`scripts/publish_papers.py` in
`HydroAgent-Lab/HydroAgent_WP`), once a day after the 07:00 (Europe/Rome) digest. Do not edit it by hand.
The website (`HydroAgent-Lab/HydroAgent-Lab.io`) checks this repository out when it builds — daily on a
schedule and on every push to its `main` — and refuses to build if the file is missing or invalid.

Summaries are generated by AI from titles and abstracts and may contain errors; the papers belong to their
authors and publishers — follow the links for the originals.

## Format (`schema_version` 1)

```json
{
  "schema_version": 1,
  "generated_at": "2026-10-23T06:30:00+00:00",
  "count": 158,
  "papers": [
    {
      "id": "SRC_DOI_10-1016-j-envsoft-2026-107142_231266919690",
      "title": "Original title, never translated",
      "type": "published",
      "included_on": "2026-09-08",
      "date": "2026-09",
      "authors": ["First Author", "Second Author"],
      "authors_total": 6,
      "venue": "Environmental Modelling & Software",
      "url": "https://doi.org/10.1016/j.envsoft.2026.107142",
      "doi": "10.1016/j.envsoft.2026.107142",
      "summary": { "en": "One-sentence AI summary.", "zh": "一句话 AI 摘要。" },
      "details": { "en": "Longer AI summary.", "zh": null },
      "limitations": { "en": null, "zh": null }
    }
  ]
}
```

| Field | Rule |
|---|---|
| `id` | Collector entry ID; unique |
| `title` | Non-empty, original language |
| `type` | `published` or `preprint` |
| `included_on` | `YYYY-MM-DD`, the Rome day the paper entered the public corpus; the website groups by its week |
| `date` | Publication date `YYYY`, `YYYY-MM` or `YYYY-MM-DD`, or `null` |
| `authors` / `authors_total` | At most four names / the full count (`>=` the list length) |
| `venue`, `doi` | String or `null` |
| `url` | `http(s)` only, or `null` |
| `summary`, `details`, `limitations` | Exactly `en` and `zh`, each a string or `null`. A missing language is `null` and is **not** replaced by the other language |

No other keys are allowed: screening evidence, scope rationale, full-text paths and review items never leave
the server. `python validate.py papers.json` checks all of the above; the `Validate` workflow runs it on every
push.
